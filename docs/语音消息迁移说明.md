# 语音消息迁移（V12）

本轮复用现有媒体、消息、审核和下载入口，仍为 74 个 HTTP + 2 个 WebSocket。接入客户端目前录制的 AAC-LC/M4A；业务代码和调度由 Java 实现，音频解码调用独立 FFmpeg 进程，不依赖 Python。

## 上传、审核、发送和播放

1. POST /media/upload，multipart 字段：media_type=voice、source=chat、conversation_id、file。
2. Content-Type 为 audio/mp4 或 audio/x-m4a；文件实际必须是 M4A/MP4 容器内单条 AAC-LC 音轨，1–2 声道、8–48 kHz，无视频/其他轨道。
3. 服务端探测并实际解码，生成 16 kHz、单声道、16 位 PCM WAV。原始容器和标签不作为最终文件保存。
4. 返回 status=review_pending、content_type=audio/wav、pipeline_version=java-voice-v1。media_metadata 包含 duration_ms、duration_seconds、sample_rate、channels、codec。
5. 后台现有审核接口可按 media_type=voice、source=chat 筛选，管理员预览返回 audio/wav。审核通过后才能发送。
6. POST /conversations/{id}/messages：

```json
{
  "type": "voice",
  "content": "[语音]",
  "media_asset_id": "media_...",
  "client_message_id": "稳定的重试标识",
  "duration_seconds": 1
}
```

- 语音不接受 media_kind；content 保留必填的旧契约。
- duration_seconds 可省略或为 0–60，服务端返回值始终按解码采样长度计算：向上取整，最高 60。客户端上报值不会覆盖实际时长。
- 幂等比较媒体 ID、消息类型、正文、引用；客户端时长只作为兼容字段，变化不会另建消息，也不会改变既有权威时长。
- 媒体必须归本人、当前会话且类型匹配，只能绑定一条消息。资料图片不能作为语音发送。
- 历史、搜索（message_type=voice）和 WebSocket 均携带媒体 ID 与权威 duration_seconds。
- 接收者用 POST /media/{id}/access-url 获取 5 分钟链接。用户/管理员的下载均返回正确音频 MIME，no-store；当前为完整 WAV 响应，未实现 Range 分段请求。
- 真正 Flutter 设备上的录音→播放全链路尚未联调；本轮通过 HTTP 音频内容解析和 WebSocket 验证，不等于手机端验收。

## 边界与失败行为

- 输入不超过 8 MiB；最短实际解码长度 0.1 秒。
- 业务上限 60 秒，为 AAC 编码尾帧允许最多 0.5 秒余量；超过 60.5 秒拒绝。返回展示秒数最高仍为 60。
- 不只看客户端时长或容器头：实际输出 PCM 也受长度限制；最多解码 61 秒，以识别伪造短时长的长音频。
- 当前仅支持 AAC-LC/M4A，不接收 MP3、WAV 原始上传、HE-AAC、Opus、视频、GIF 或任意文件。输出 WAV 不代表允许上传 WAV。
- 文件格式/MIME/音轨不合要求返回 400 MEDIA_TYPE_INVALID；时长不符为 400 MEDIA_DURATION_INVALID；过大为 413。
- 每实例一次只处理一个语音上传，繁忙返回 429 MEDIA_BUSY；每个探测/解码进程限时 20 秒，超时中止；流程是同步处理，尚未改为后台任务队列。
- 工具未配置或不可启动返回 503 MEDIA_PROCESSOR_UNAVAILABLE；不会保存一个“已处理成功”的假音频。
- 子进程使用固定参数数组，不经 shell；仅开放本地文件/必要的管道协议，关闭外部轨道加载，不传数据库或 JWT 环境变量。
- 输出和输入均有字节上限，单次 FFmpeg 内存分配限额为 64 MiB。这不是整个进程内存总额保证；生产环境还需操作系统/容器资源隔离及容量测试。
- 处理临时文件在完成或失败后清理。发送事务失败保持媒体未绑定，可用相同请求重试。

## 私密访问和清理

沿用 V11 的会话权限：非成员无权访问；隐藏/个人清空只撤销本人访问；撤回、拉黑、拒绝审核、媒体删除或登录失效会使对应旧链接不可用。撤回后媒体 ID 置空、duration_seconds 返回 0。已下载到客户端的音频无法由后端远程删除。

语音不能写入头像/相册。删除好友仍可查看历史，但不能再上传发送。注销清理覆盖该私人会话双方音频，实际文件通过可重试删除任务清理；自动到期清理保持开启。本机冒烟不修改注销期限或强制清理。

V12 为媒体增加 duration_ms，为消息增加 duration_seconds，扩展 voice 类型约束。存储只允许规范生成的 media_<随机ID>.png 或 .wav 文件名。

## 本机工具与部署配置

- 本轮在 Java 工程 .tools/ffmpeg 内安装 FFmpeg/ffprobe **9.0.1**，校验 ZIP SHA256：
  fec81ae03971d9dd4be3ebe02e263bd2ec1d789483f931bdba5f5715e65da2e9
- 安装记录：.tools/ffmpeg-install.json；构建和本地启动脚本读取该记录，不修改全局 PATH。
- 可用 tools/install-audio.ps1 从已缓存且校验通过的 ZIP 重建工具。脚本固定本次摘要；若远端 latest 更新而本机无缓存，脚本会拒绝新版包，需审核版本并更新固定摘要。
- 其他环境设置 JAVA_MEDIA_FFMPEG 和 JAVA_MEDIA_FFPROBE 为绝对可执行路径。工具缺失不影响已有文字/图片功能，但语音上传返回 503。
- Linux CI 配置已增加 FFmpeg 安装及环境变量；本轮未运行远程 CI。
- 本机发行包的许可证、文档仍保存在解压目录；不将原生工具塞入 JAR。

Windows 构建渠道取自 [FFmpeg 官方下载入口](https://ffmpeg.org/download.html) 指向的 [Gyan 构建站](https://www.gyan.dev/ffmpeg/builds/)。进程参数依据 [FFmpeg 文档](https://ffmpeg.org/ffmpeg.html) 和 [MOV 外部轨道说明](https://ffmpeg.org/ffmpeg-formats.html#mov_002fmp4_002f3gp)。
