# 群组、分享链接与划卡迁移

## 新业务规则（2026-09-17 用户确认）

普通账号与会员普通喜欢均无每日或付费额度。单向喜欢不创建会话；双方普通喜欢才原子创建配对、好友关系、聊天及两条通知，重复和并发请求不会重复创建。超级喜欢已取消，旧端点返回 410 / EXPLORE_SUPER_LIKE_REMOVED，无业务副作用。

回退同样不设每日额度；返回 likes_unlimited=true、undo_unlimited=true、undo_remaining_today=null。回退撤销最近尚未撤销的普通喜欢/跳过；已经形成的配对和好友关系保留。候选每页最多 10 张属于分页大小，不是每天可喜欢的上限。候选在数据库分页轮换，不将全量候选装入 Java 内存。

登录、拉黑、账号状态、资料审核和经人工确认的人像条件继续生效。人工审核 portrait_manual_approved 标记实际落库并可被撤销，不伪装自动人像识别。待注销账号不能继续划卡；注销后清理动作、配对和私聊。

## 群组和聊天

支持创建、列表、搜索、加入申请、密码/问题、仅邀请、管理员、移除、退出、群主转让、解散。密码和问题答案只存 PBKDF2 摘要。容量在群组行锁内检查，并发加入不会超额。群主不能直接退出。

群消息独立收件状态、未读、通知、WebSocket/ACK/typing 和媒体权限复用既有聊天能力。退出/被移除即失去消息和已签发媒体 URL 的访问权。新加入或再次加入不恢复加入前的历史（相对旧版更严格）。注销群主转让给最早的有效成员，无有效继任者则解散；删除其媒体、匿名化消息，保留其他成员的群聊和附件。

## 群分享接口

- GET /groups/{id}/share-link：当前成员获取 share_url、share_title、share_text。
- GET /group-links/{code}：匿名读取群名、群口令、入群规则、人数和必要问题；不返回成员列表、群主、会话 ID、密码或答案。
- GET /g/{code}：浏览器邀请页，提供群口令，含 Open Graph 元数据、HTML 转义、no-store、CSP 和 noindex。
- POST /groups/join-by-link-code?link_code=...：登录后申请，仍检查密码/问题/审核/人数/仅邀请规则。

新群口令为随机 32 位十六进制字符串。解散群后公开链接返回 404。分享链接不是直接入群的授权凭证。

配置 JAVA_GROUP_PUBLIC_BASE_URL 为 HTTPS 源站（不含路径、查询或用户名密码），仅 localhost 允许 HTTP。用户指定测试域名 https://sssuuil-server.top 已存入本地 .tools/local-development.json 的 groupPublicBaseUrl；启动脚本读取此字段，环境变量可覆盖。默认配置仍是本地地址，真实凭证不提交。

2026-09-17 本机检查：域名查询只返回 SOA，没有地址；curl HTTPS 报无法解析域名。尚未配置 DNS、TLS 或反向代理，不能宣称公网可分享。公网路由需要同时转发 /g/ 和 /group-links/ 到 Java 服务。

## 客户端待接入

当前 Flutter 仍有超级喜欢入口和回退次数 UI。本批只读客户端，未修改。接入时移除超级喜欢相关按钮/徽标/权益，使用 unlimited 标记显示无限回退，消费新的链接元数据，接入系统分享面板和应用链接解析。

微信、QQ、TikTok 等真实分享、平台预览、App Links/Universal Links、安装后的打开行为需要客户端和公网环境联调。当前公开页提供手动使用群口令的后备流程，不冒充已完成一键拉起或平台 SDK 接入。
