## 接入顺序

1. 使用 tools/inspect-server.sh 只读盘点可用内存、Swap、磁盘、端口、进程和容器资源。脚本不读取环境变量、私密配置或数据库内容。
2. 按实测预算配置 API、数据库、媒体 Worker 的 OS 内存/CPU 上限和连接池。Java -Xmx 只是堆上限，FFmpeg 和 JVM 本地内存不包含在内。
3. 本机构建 JAR，服务器只运行。独立目录、账号、端口、数据库和存储，保留 Python 工程与无关项目。
4. 先验证 Java 内网就绪、业务烟测，再配置选定域名的 Nginx/HTTPS/WSS 和群链接路径；部署前确认实际路由及证书，避免影响无关站点。
5. 压测注册/登录、配对聊天、多人群聊及同时转码；记录 RSS 峰值、Swap、响应分位值和 OOM。是否需要扩容依据实测决定。
