# 礼物安全设置与风险审计（V25）

迁移 GET/PATCH /live/gift-safety/me、GET /admin/gift-risk/events、POST /admin/gift-risk/events/{id}/resolve、PATCH /admin/gift-risk/users/{id}/age-status。

普通用户可设置个人单笔/单日限额、提醒与阈值、榜单身份公开同意和首次设置提示确认；用户无法自行修改年龄核验状态。个人限额不能超过平台上限，设置 null 恢复平台值。默认单笔 10000、单日 20000、二次确认阈值 500 金币，均有 JAVA_GIFT_* 配置；年龄核验默认要求开启。

今日消费按 UTC 日界统计已提交 gift_charge 账本交易，排除有冲正交易的原记录；剩余额度最低为零。只统计礼物扣款，不包含充值或通话。限额校验与实际送礼扣款、连击、频率和确认票据将在送礼模块接入，当前不能将本批当作已经执行消费拦截。

Owner/Operator 可处理风险和调整年龄状态；Auditor 只读。年龄变更、风险记录和操作审计原子提交，年龄状态不是主播资格，也不是外部实名认证证据。风险事件只能从 open 处理为 reviewed/dismissed，锁内校验阻止重复处理。列表支持状态、类型、用户过滤，最多 500 条。

当前尚无关联送礼财务记录，注销清理安全设置与风险事件。送礼财务接入时会单独迁移财务关联留存策略，避免财务历史随注销删除。

GiftSafetyIntegrationTests 使用 HTTP/PostgreSQL 验证权限、参数、隐私、并发、回滚、注销和真实账本冲正后的消费统计。合成账本测试不代表真实送礼或付款。
