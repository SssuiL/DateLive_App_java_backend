# 主播资格与人工审核（V23）

迁移六个旧接口：GET /live/host-verification/me、POST /live/host-verification/applications、GET /admin/host-verification/applications、POST /admin/host-verification/applications/{id}/resolve、POST /admin/host-verification/qualifications/{user}/suspend 和 /restore。

## 资格流程

保留旧业务年龄与协议规则：申请时拒绝未来出生日期、未满 16 周岁及未同意协议；16–17 岁需 guardian_consent。以上是旧业务契约迁移，不是第三方年龄验证。默认人工审核，任何申请都不会自动通过；Owner/Operator/Auditor 沿用旧版 host_verification 读写权限。

姓名只保存脱敏值，证件号保存 HMAC 与脱敏值，不保存明文。接口不返回哈希；审计不记录提交身份明文。申请与审核均锁用户，数据库限制同一用户仅有一条待审申请。审核结果、资格、通知和审计在同一事务提交；重复审核返回 409。

拒绝必须填写非空原因，之后可重新申请。审核通过时才根据 allow_gifts 显式授权收礼；重新申请立即取消旧收礼资格。暂停禁止重新申请；已经待审的申请仍可审核，但审核不能解除暂停。恢复及到期解除暂停不自动恢复收礼资格。拒绝后的定时暂停到期可重新申请，永久暂停仍需管理员处理。

JAVA_LIVE_HOST_VERIFICATION_REQUIRED 默认 true；显式关闭资格前置条件也不能绕过有效暂停。JAVA_LIVE_HOST_AGREEMENT_VERSION 默认 2026-07，应在上线前配置正式协议版本。assertCanStart/assertCanReceive 供后续直播房间和送礼事务接入，目前尚未计为开播或送礼端到端验收。

## 通知与注销

审核和暂停生成官方站内通知，沿用免打扰、推送偏好与实时通知 outbox；真实推送供应商未接入。注销预览列出认证申请和资格，自动注销清理会删除这些身份资料，保留不含明文身份的操作审计。已注销账号无法再创建认证资料。

## 验证边界

HostVerificationIntegrationTests 覆盖出生日期、同意、脱敏、并发申请、审核、通知、暂停/恢复、旧申请失效、过期暂停、回滚及注销。运行中服务用 tools/smoke-host-verification-local.ps1 验证。

当前仅迁移人工工作流，不接入证件真伪、人脸核身或外部身份服务；测试中的批准是合成账号。真实审核运营和直播供应商联调独立验收。

补充：未通过认证但处于暂停的用户，管理员解除暂停只恢复到待申请/待审核状态，不授予开播或收礼资格，避免审核拒绝与永久暂停组合造成无法恢复的状态。
