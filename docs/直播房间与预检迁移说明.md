# 直播房间与开播检查（V24）

本批迁移 12 个 HTTP 接口：分类、创建/列表/详情、直播会话、房间预检/开始/结束、进入/离开、网络探测及后台预检查询。不是整套直播功能验收。

## 本地流程

默认 JAVA_LIVE_PROVIDER=disabled、JAVA_LIVE_MOCK_ENABLED=false。显式 tools/start-local.ps1 -DevelopmentLive 启用本地 Mock，生产环境拒绝 Mock。会话仅返回 is_mock 和 mock provider_room_id，push_url/playback_url 为 null，不伪造真实推流能力。

创建草稿后，完成主播人工审核并通过设备/网络预检，使用一次性票据开播。检查摄像头/麦克风权限与可用性、网络指标、本地文本规则、本人封面审核和已有直播。设备和网络指标来自客户端上报，不是服务端可信硬件认证。缺失封面仅提示；网络指标缺失或延迟/带宽警告必须显式确认；严重失败不发票据。

预检票据使用 40 字节安全随机数，只存 SHA-256，5 分钟有效；绑定主播和房间。新的检查会使旧票据失效，即使新检查失败。开播时再次检查资格、服务商与内容状态，并在同一事务消费票据、切换房间、加入主播。用户锁和数据库唯一索引保证同一主播不能并发开启多个房间。

## 房间及媒体

草稿仅本人可见；观众进入直播后参与者计数更新，重复进入不会重复建记录；被踢者不能自行重入。主播通过结束直播离开，结束会将活跃参与者全部退出。结束的房间对普通观众不可见。

封面只接受本人 profile 图片，预检要求审核通过。输出沿用短期签名媒体 URL，实际读取复查活跃直播/资料引用、媒体审核、用户状态及拉黑关系。草稿与直播封面纳入草稿回收引用保护；结束后若无其他有效引用，旧签名读取失效并可按既有期限回收。

注销会清理用户参与记录和其主播房间，房间关联预检/成员级联清理。金融礼物尚未接入；后续接入财务历史时会重新明确直播历史留存与匿名化策略。

## 验证与剩余

LiveRoomIntegrationTests 覆盖 19 项真实 HTTP/PostgreSQL 测试：资格、票据、警告确认、并发、房间状态、模拟开关、封面权限/回收/变更、注销及后台票据隐私。本地 tools/smoke-live-room-local.ps1 生成运行中服务验收报告。

直播 WebSocket/弹幕、点赞广播、房间治理、关注/预约、连麦、音视频凭证/回调、恢复超时、送礼与结算仍待迁移。真人推流、Flutter 与云端资源测试未进行；本批路由映射不代表这些关联行为完整。

完整回归 392 项通过，运行中验收发现的内容类型错误补充 HTTP 415 回归后，19 项直播专项测试再次通过并完成最终打包；累计验证 393 项不同测试。本地 14 项验收通过。
