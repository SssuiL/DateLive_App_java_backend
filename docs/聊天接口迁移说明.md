# 聊天接口迁移说明

## 本轮接口

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | /conversations/ | 当前好友会话，按本人置顶、最后活动时间、ID 倒序 |
| GET | /conversations/page | 游标分页；limit 默认 30，范围 1–100 |
| GET | /conversations/{conversation_id} | 本人的会话详情 |
| GET | /conversations/{conversation_id}/messages | 本会话全部历史，按时间与 ID 正序 |
| GET | /conversations/{conversation_id}/messages/page | 历史分页；limit 默认 30，范围 1–50；从最新向过去翻页，每页内部正序 |
| POST | /conversations/{conversation_id}/messages | 发送文本或已审核图片/语音，可附 client_message_id、reply_to_message_id |
| POST | /conversations/{conversation_id}/read | 本人的入站消息标记已读，并清零本人会话未读数 |
| PATCH | /conversations/{conversation_id}/settings | 更新本人 pinned / muted；未传或 null 字段保持不变 |

所有接口均需用户 Bearer Token。/conversations 同时支持无尾斜杠别名，只按一个接口计数。目前仅接入好友私人会话。

## 行为和兼容边界

- ConversationOut / MessageOut / PageOut 保留旧客户端字段形状。V12 支持 text、image（PNG/JPEG 图片、静态贴纸）和 voice（AAC-LC/M4A 输入，WAV 输出），content 1–2000 字；其他媒体类型明确返回 422。详见 [聊天图片迁移说明](聊天图片迁移说明.md) 与 [语音消息迁移说明](语音消息迁移说明.md)。
- 文本完整保存，会话 last_message 摘要最多 500 个 Unicode 码点，避免长消息造成会话字段写入失败。
- client_message_id 可选，长度 8–64，去除首尾空白后再次校验。同会话、同发送者、同 ID 重试返回原消息；内容或引用不同返回 409。缺省时每次请求创建新消息。
- 引用必须指向同一会话中的已存在消息；响应包含原消息预览。V9 已实现撤回与引用脱敏，详见消息交互迁移说明。
- 会话、消息查询严格校验成员身份，任一方向屏蔽后均不可读取或发送。未知会话与越权均返回 404。
- 删好友后会话从列表隐藏，原成员仍可访问历史，不能继续发送；重新成为好友时复用历史会话，沿用旧业务行为。
- 对方非 active 时不可访问。本人注销冷静期内可读取可见历史及操作个人设置/已读，不能发送新消息。
- 置顶、静音、未读数分别保存在各成员状态中；一个人的设置不会修改另一个人的设置。
- 每用户每分钟最多 120 次新消息，幂等重试不重复计数。
- 为兼容旧接口保留不分页历史入口；长历史客户端应使用 /messages/page。分页以时间与 ID 双字段定位，时间相同也可稳定翻页；会话游标额外包含本人置顶状态。跨页期间置顶或最后活动改变时列表可能移动，客户端需支持刷新与按 ID 去重。

## 消息、通知与事务

发送时一次事务完成消息、双方回执、接收方未读数、会话摘要、聊天 outbox、站内通知和通知未读 outbox。任一步失败全量回滚，不出现通知已发而消息未落库的中间状态。

写入锁顺序与社交模块一致：双方用户按 ID 顺序 → 会话 → 成员状态/消息/回执。已读与发送使用同一顺序，避免清零未读时漏掉并发新消息；锁后重新校验成员、屏蔽与登录会话。

发送者初始已读，但不伪造接收方送达。接收方明确调用 read 后才写入已读及送达回执。重复 read 不重复追加 message.read outbox。

通知依次检查聊天开关、旧版 UTC 夜间时段、会话静音和有效设备。被抑制的推送仍保留站内通知与会话未读数。聊天会话已读与通知中心已读是独立状态，沿用旧接口行为。

## 尚未交付的实时能力

V10 已接入 WebSocket 消费者和在线租约。chat_change_outbox 的 delivered_at 表示交付给持久实时事件队列，不代表客户端收到；消息 ACK 才更新送达回执。participant_online 和 participant_last_seen_at 现在返回成员在线状态与最近连接/续期时间。真实厂商推送仍未接入，见 [实时通信迁移说明](实时通信迁移说明.md)。

后续实时消费者必须重新验证账号、成员、好友及屏蔽状态，并处理重试和去重，不能直接把历史队列条目视为仍可投递。当前拉黑已抑制双方 pending 聊天通知。

群聊、临时会话、视频/动态 GIF 附件和真实推送继续迁移；当前版本不声称完整聊天服务上线。

## 数据与注销清理

V8 增加 messages、message_receipts、chat_change_outbox。消息发送者与回执用户受到会话成员外键约束，引用通过复合外键限定同一会话。

自动注销先删除该私人会话的聊天事件与消息，级联清除回执，再删除会话及成员，并清理 chat-send 限流桶。预览增加 messages 计数；users 外键覆盖测试已扩展。未来群聊成员退出/注销不可直接复用当前私人会话整体清除策略。
