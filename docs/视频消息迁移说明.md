# 视频消息迁移说明

工程：E:/Project/backend-java。新增数据库迁移 V13；复用已有 HTTP 和 WebSocket 路由。

## 上传和消息

- POST /media/upload：media_type=video、source=chat、conversation_id，以及文件。
- 接受 MP4/MOV/M4V MIME（video/mp4、video/quicktime、video/x-m4v）；实际容器由 FFprobe/FFmpeg 解析。
- 视频轨仅 H.264 或 HEVC，恰好一条；允许无声或一条 AAC 音轨（1–2 声道、8–48 kHz），其他轨道拒绝。
- 输入最多 32 MiB、8,294,400 像素、单边 3840、60fps；时长 0.1–60 秒，允许最多 0.5 秒编码余量。
- 解码后统一 H.264/yuv420p MP4，最长边 1280、30fps；有声视频转 AAC，清除源 metadata 和章节，启用 faststart。
- 生成最长边 320 的 PNG 封面；本地文件与数据库均不暴露公开下载路径。
- 仍需人工审核。发送 type=video、media_asset_id、client_message_id；不设置 media_kind。duration_seconds 使用服务端转码后的探测结果，向上取整且最多 60。
- 会话、归属、单消息绑定、好友状态、幂等与 outbox 同事务沿用图片/语音实现。

## 封面与播放

- POST /media/{id}/access-url?variant=thumbnail 获取封面签名地址（兼容旧接口 variant=cover）；原文件省略 variant 或使用 original。
- 管理员 POST /admin/moderation/media/{id}/preview-url 支持相同变体并记录审核预览审计。
- 签名令牌绑定资产、当前登录会话及 variant，有效期五分钟；每次下载仍检查登录状态及消息可见性。不能用封面令牌读取原文件；客户端可从令牌恢复变体并续签，旧无 variant 令牌按 original 处理。
- 下载支持单段 Range：bytes=0-31、bytes=32-、bytes=-16。成功返回 206 与 Content-Range；无效、多段和越界返回 416 与 bytes */总长度。
- 原有语音和图片下载也使用相同响应组件。Cache-Control 为 private, no-store；不能替代 Flutter 自有缓存的撤销管理。
- 个人隐藏、清空、撤回、拉黑、会话令牌失效、审核拒绝和删除会影响相应用户的原文件及封面访问。
- 删除和账号到期清理同时删除 MP4/PNG，任一删除失败保留清理任务供重试。账号到期 Worker 保持开启。

## 处理边界

- 单实例同时一条视频转换，忙时 429；子进程各最多 60 秒，超时 503；不是异步队列。
- 仅本地 file 协议，禁用外部 MOV 轨道引用；命令使用固定参数和服务端临时路径。
- 子进程环境不继承数据库/JWT 凭证。限制输入、输出大小、线程与时长；临时文件完成或失败后清理。
- 超长视频被拒绝，不自动截成可发送视频；源声明时长与转码结果均检查。
- 工具缺失返回 503。复用 .tools/ffmpeg，安装/构建/启动脚本和 CI 环境沿用语音配置。
- 本轮没有真实内容审核/安全扫描供应商、云存储、进程沙箱或生产容器资源限额。4K/HEVC 在弱机器上可能触发超时，尚未进行容量与设备兼容测试。

## 验证入口

- VideoIntegrationTests：真实 H.264/AAC 和 HEVC 合成文件、静音 MOV、损坏/超长/超大/错误 MIME 拒绝、实际 PNG 解码。
- 覆盖审核、分段字节正确性、非法 Range、跨人/跨会话/资料复用拒绝、WebSocket、并发幂等、回滚、原文件/封面撤权、删除/注销清理。
- tools/maven.ps1 -B verify；tools/smoke-video-local.ps1；结果见重构进度和 docs/local-video-smoke.json。
- 合成测试不代表 Flutter 手机端视频播放已验收。Python/Flutter 源码未修改。
