# 礼物目录与素材迁移（V22）

迁移旧 GET /live/gifts、GET/POST /admin/live-gifts、PATCH /admin/live-gifts/{id} 和 POST /admin/live-gifts/{id}/assets/{type}，另提供 Java 素材读取 GET /gift-assets/{id}。

保留 12 项默认礼物、价格、排序、展示层级、时长、客户端最低版本、渲染类型及上下架。公开目录仅返回上架项，不暴露后台 ID、状态或审计字段。Owner/Operator 可修改，Auditor 只读；修改均校验当前管理员状态并记录审计。创建的重复编码返回 409。

## 素材与事务

图标支持 PNG/JPEG/WebP，限制 5 MiB；Lottie UTF-8 JSON 限制 2 MiB。PNG/JPEG 实际解码并限制 400 万像素，WebP 检查 RIFF 长度与分块边界，但未做完整像素解码。Lottie 验证核心字段、帧率和时间轴；不是完整渲染或安全扫描。alpha_video 保留目录字段，上传接口仍与旧版一样仅支持 icon/animation。

素材使用独立 live_gift_assets 表保存字节；目录列表不会加载素材字节。上传、目录 URL、版本号及审计记录在同一事务完成，任一步失败全部回滚。使用不可猜测的服务器生成 ID，忽略上传文件名及 MIME，按实际校验类型返回 nosniff/CSP。素材是公开运营内容，旧版本保留可读以支持已发礼物的资源快照；下架只影响公开目录，不会销毁资源或历史展示。

JAVA_GIFT_PUBLIC_BASE_URL 配置素材 URL 前缀，本地默认 http://127.0.0.1:8200。公网部署时必须设置为经过验证的 Java 公网地址。已有第三方 URL 不由服务器下载，限制为 HTTP(S) 且禁止 URL 内凭证。修改 animation_url 清除旧校验和/大小，任何有效字段更新增加资源版本；修复旧实现直接修改 URL 却保留过期校验和的问题。

## 验证和剩余边界

GiftCatalogIntegrationTests 使用实际 PostgreSQL/HTTP 验证目录、上下架、权限、参数、上传、公开读取、原子回滚及并发版本更新。tools/smoke-gift-catalog-local.ps1 验证运行中 API，报告为 docs/local-gift-catalog-smoke.json。

数据库素材存储适用于当前有限运营素材，不能作为无限上传容量保证；后续云存储、旧版本回收与 CDN 仍需独立验证。尚未验收 Flutter 动画播放，也未将本批计为送礼扣款、风控、主播分账或结算完成。
