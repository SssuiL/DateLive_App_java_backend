# 动态与评论迁移（V19）

只读对照旧工程 app/api/posts.py、app/services/post_service.py、schemas/domain.py 和媒体访问规则，新增 19 个 HTTP 接口。Java 数据库独立，没有导入旧数据库。

## 行为

- 文字、图片、语音和视频动态；默认好友可见，也支持公开和仅自己可见。好友动态流只列本人及好友，陌生人的公开动态可从用户主页或详情访问。
- 点赞幂等；评论支持根评论、多层回复归到同一线程、根评论游标分页和有限回复预览。删除根评论保留已有回复及删除占位。
- 动态作者可管理自己动态下的评论，包括删除待审核评论；这不授予读取未审核附件的权限。
- 图片/GIF 评论、图片/视频 Emoji 点评与媒体保存偏好。保存偏好限制下载接口，不是防复制或 DRM。
- 动态和评论复用上传、转码、派生图及人工审核流程。未完成处理或审核的媒体不能发布给其他用户；媒体审核结果同步动态/评论状态。
- 既有签名链接仍逐次检查权限：删除、审核驳回、拉黑、取消好友和注销后访问会失效。
- 媒体绑定与内容发布同事务；锁顺序为相关用户、动态、附件。审核遇到并发绑定变化返回 409，可重试。
- 动态作者注销时清除本人正文、附件引用、互动记录和相关通知；保留其他人的回复内容。草稿清理不误删仍用于有效动态或评论的附件。
- 普通划卡喜欢仍无限制。评论保留旧接口的防刷默认值 8 次/10 秒，媒体点评 12 次/10 秒。

## 验证范围与限制

PostIntegrationTests 覆盖访问控制、并发幂等、事务回滚、分页、回复占位、审核、媒体绑定、异步任务、真实 FFmpeg 语音/视频转码、删除与审核竞争和注销。完整测试数量以 migration-status.json 中最终验证记录为准。

tools/smoke-posts-local.ps1 通过运行中的本地 HTTP API 生成合成账号，调用管理审核与媒体处理；报告见 docs/local-posts-smoke.json。不会访问或写入旧 Python 服务。

文本审核仍是当前本地规则，媒体审核是人工/测试流程，未声称接入真实云审核供应商。外部存储、病毒扫描、推送、Flutter 页面与云端验收仍分别跟踪。GIF 的 media_kind 与实际 MIME 不符会拒绝，避免把 GIF 伪装成静态贴纸。
