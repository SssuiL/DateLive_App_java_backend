# Java 编译与本地运行环境

工程：`E:/Project/backend-java`。

| 项目 | 状态 |
| --- | --- |
| JDK | Eclipse Temurin 25.0.4.1+1 LTS，实际 javac 编译及 java 执行通过 |
| Maven | Wrapper 3.3.4 / Maven 3.9.16，实际构建通过 |
| Spring Boot | 4.1.1，已构建可执行 JAR |
| VS Code | 已确认 oracle.oracle-java 26.0.2，工作区配置指定项目 JDK |
| Docker | Engine 29.7.2，已实际运行独立 PostgreSQL 集成测试 |

JDK 安装于 `.tools/jdk/jdk-25.0.4.1+1`，下载来源和 SHA256 校验值保存在本机 `.tools/jdk-download.json`。Maven Wrapper 缓存与依赖缓存也在 `.tools`。

系统全局 PATH 不要求有 java/javac/mvn。从 PowerShell 7 运行 `tools/maven.ps1 verify`，脚本只为本次构建设置 JDK，结束后还原环境。Linux CI 使用已配置的 JDK 与 `./mvnw -B verify`。

VS Code 用 Oracle Java 插件即可，不需要再安装专用 IDE或另一套 Java 语言服务。项目 `.vscode/settings.json` 的 `jdk.jdkhome` 和 `jdk.project.jdkhome` 使用 workspaceFolder 定位 JDK。

本地开发使用 `tools/start-local.ps1`，API 为 http://127.0.0.1:8200，独立数据库为 127.0.0.1:15433；`tools/stop-local.ps1` 停止 API。数据库卷保留。运行的是 JAR 副本，代码更新后需要重启。

`-DskipTests package` 仅验证打包，不能代替 `verify`。本轮已执行包含异步媒体与草稿回收、图片衍生图、GIF/文件、视频、语音、聊天图片、实时 WebSocket、聊天、社交与注销清理的完整回归测试，不把跳过测试的构建当成测试通过。当前 232 项测试通过不等于全后端实现完成。

编译与测试日志保存在本机 `.tools/media-jobs-verify.log`；账号冒烟与采样报告在 `docs/local-auth-smoke.json`。日常 API 日志在 `.tools/run/api.log` 和 `api-error.log`。

## 音视频工具

FFmpeg/ffprobe 9.0.1 位于 .tools/ffmpeg，SHA256 校验及路径见 .tools/ffmpeg-install.json。tools/install-audio.ps1 可从校验后的安装包重建；构建和本机启动脚本自动读取路径，不改全局 PATH。其他部署环境设置 JAVA_MEDIA_FFMPEG / JAVA_MEDIA_FFPROBE。缺少工具时音视频上传返回 503；音视频测试不会跳过。详见语音消息迁移说明。
