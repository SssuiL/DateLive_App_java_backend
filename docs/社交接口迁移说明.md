# 用户目录、好友与拉黑迁移

## 接口

| 方法 | 路径 | 返回 |
| --- | --- | --- |
| GET | /users/ | 公开用户列表，仅 id、nickname；q 最长 100 字，limit 默认 20，范围 1–50 |
| GET | /users/{user_id} | 公开用户；不可见时 404 |
| POST | /friends/requests | 申请记录；target_user_id、可选 message（最多 120 字） |
| GET | /friends/requests | 当前用户收发的可见申请 |
| POST | /friends/requests/{request_id}/accept | 通过申请 |
| POST | /friends/requests/{request_id}/reject | 拒绝申请 |
| GET | /friends/ | 好友公开资料，复用资料与媒体审核可见性 |
| DELETE | /friends/{target_user_id} | {"status":"deleted"} |
| POST | /safety/blocks | 拉黑记录；block_type 为 block 或 hide_from_explore，默认 block |
| GET | /safety/blocks | 仅本人创建的拉黑记录 |
| DELETE | /safety/blocks/{block_id} | 204；不存在或非本人记录为 404 |

所有接口都需要用户 Bearer Token。/users 与 /friends 同时支持无尾斜杠写法；接口计数按规范路径计算，不重复计入别名。

## 契约与并发边界

- 搜索按完整用户 ID 或昵称字面子串匹配；空关键字返回空列表，百分号与下划线不是通配符。仅展示 active 且不存在任一方向屏蔽的账号；不返回手机号或密码。
- 新申请、通过/拒绝及新增屏蔽要求双方 active；不会向注销冷静期或不可用账号建立新关系。删除好友与解除屏蔽仍允许冷静期内的本人操作。
- 拒绝对自己申请或屏蔽；只允许接收方审批。相同方向未处理申请重复提交返回原记录，不修改原留言、不重复通知。
- 已经是好友时申请返回 409；已结束的申请不可改判。重复同结果审批幂等，删除好友后重放旧 accepted 申请不会重新建立关系。
- 双向申请通过后统一变为 accepted，只建立一份排序后的好友关系和一个好友会话。删除后重新申请并通过，复用原好友会话。
- 两用户写事务按用户 ID 顺序加行锁，再修改关系；事务内重新校验登录会话。避免交叉审批死锁及与自动清理并发时写回已注销账号。
- 新申请每用户每分钟最多 30 次，重复 pending 申请不占新次数。
- 两类屏蔽均沿用旧目录/资料的双向不可见语义；不会因为重复 hide_from_explore 降级已经存在的 block。
- 屏蔽关闭双向 pending 申请，隐藏好友资料及申请列表，并抑制未发送的好友申请通知。好友关系保留，解除屏蔽后恢复可见；已拒绝的申请不会自动恢复。

以上补充了旧实现缺少的幂等、最终状态保护与屏蔽校验，同时保持主要路径、返回字段和删除好友保留会话的契约。

## 通知与会话基础

申请、通知偏好初始化、notification_events 和 notification_change_outbox 在同一事务写入；任一步失败全部回滚。按申请 ID 去重。站内记录与未读数可通过现有通知接口查询、标记已读。

通知依次检查好友申请开关、夜间免打扰、有效推送设备；关闭推送仍保留站内通知。夜间时间按旧实现的 UTC 比较，支持跨午夜，起止相同表示不启用时段限制。

存在设备且未被抑制时标记 pending/offline_push，仅表示待投递。尚未调用真实推送供应商、尚未消费实时 outbox；不声称已发送系统推送。

通过申请建立 conversations 与 conversation_member_states 的最小基础：双方成员、未读数、置顶/静音默认值。聊天 HTTP、消息、WebSocket、群聊等在后续迁移中实现。

## 数据迁移与清理

V7 为 blocks 增加 ID、类型、时间，并建立 friend_requests、friendships、conversations、conversation_member_states。原有 blocks 数据自动补齐字段；不读取旧 Python 数据库。

自动注销已纳入申请双方、好友双方、私人好友会话及成员、相关通知、个人申请限流桶。预览增加社交关系与会话计数，测试将实际 users 外键集合与清理策略集合比对。后续新增群聊/消息表时必须继续扩展清理规则，不可直接复用私人会话整表删除规则。

## 验证

SocialIntegrationTests 新增 15 项测试；与 AccountLifecycleTests 合并的 27 项测试全部通过。覆盖契约、参数、权限、限流、幂等、并发审批、屏蔽与审批竞态、通知抑制、事务回滚、注销隔离与并发防复活。

tools/smoke-social-local.ps1 只创建 Java 本地合成账号，验证完整社交流程；不会修改任何注销截止日期或强制清理账号。
