# 消息交互迁移（V9）

## 接口

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | /conversations/{conversation_id}/messages/{message_id}/recall | 撤回本人发送且未超过 2 分钟的消息 |
| GET | /conversations/{conversation_id}/messages/search | 关键词/类型筛选和游标分页 |
| DELETE | /conversations/{conversation_id}/messages/{message_id} | 仅对本人隐藏，返回 status=hidden |
| DELETE | /conversations/{conversation_id}/messages | 仅清空本人的可见历史，返回本人会话状态 |

所有入口使用已有会话成员、账号状态、屏蔽与会话令牌校验。写入继续采用双方用户排序锁 → 会话锁 → 消息/回执/通知的事务顺序。

## 撤回

- 接收方不能撤回发送方消息，返回 403；超出 120 秒返回 409。重复撤回返回同一个撤回状态，即使首次撤回后已超过窗口也不重复产生事件。
- 用户输出 content 变为“消息已撤回”，引用预览变为“原消息已撤回”，同时设置 is_recalled、recalled_at、recalled_by_user_id。
- 会话摘要按本人最新可见消息计算，撤回旧消息不会覆盖较新的摘要。
- 新引用不得指向已撤回消息。原始正文保留用于既有幂等请求的内容比对，用户查询、重试响应、搜索与引用均不暴露撤回正文；账号最终注销时物理清除。
- 待投递的 message.created 事件被移除，新增一个 message.recalled 事件，未发送通知改为 suppressed/message_recalled。
- 历史保留撤回占位消息；撤回不伪造对方已读或送达，不直接清零对方未读数。
- 当前只支持好友私人会话，不包含群管理员撤回权限。

## 个人隐藏与清空

本轮明确采用个人语义。旧 Python 的整段清空会直接删除双方消息；Java 保持相同 HTTP 路径，但只更新操作人对应 message_receipts.hidden_at。没有全局删除消息或对方记录。

- 本人普通历史、分页、搜索及会话摘要都过滤隐藏消息；对方仍可看到自己的历史。
- 若原引用消息对本人已隐藏，对本人的 reply_preview 返回 null，避免从引用重新显示被隐藏内容。
- 隐藏/清空按当前仍可见的入站未读消息重新计数，不写入已读或送达回执。后续 read 也会跳过隐藏消息。
- 清空不会影响随后收到的新消息。与发送并发时，两次操作通过同一锁顺序串行化，最终未读数对应实际可见消息。
- 隐藏和清空幂等；重复操作不重复产生变更事件。隐藏后的 client_message_id 重试返回 404，不重新创建或恢复旧消息。
- 不能引用本人隐藏的消息，也不能撤回本人已经隐藏的消息。
- 本人待发送的关联通知被抑制，但通知中心已读状态与聊天已读继续独立。
- message.hidden / conversation.cleared 事件仅用于操作人自己的多端同步；后续实时消费者不得广播给对方。

## 搜索

- q 最长 100 字；按不区分大小写的字面子串搜索，百分号、下划线和反斜线不是通配符。
- 关键词或 message_type 至少有一个。类型采用旧枚举 text/image/emoji/video/voice/file；目前只存储 text，其余合法筛选返回空结果，不表示已经支持附件发送。
- 排除撤回消息及本人隐藏消息。limit 默认 30，范围 1–50。
- 按 created_at、id 倒序返回，游标形状沿用历史接口；同一时间的消息仍可稳定翻页。注意普通历史分页的每页内部为正序，搜索结果为倒序。
- 非法游标或筛选返回 400，超限参数返回 422。会话权限与屏蔽始终生效，不能用其他会话的 ID 越权查询。

## 数据与验证

V9 为消息增加撤回时间和操作者，为回执增加个人隐藏时间及可见索引，扩展聊天 outbox 事件类型。新增 users 外键已加入注销清理策略；隐藏记录、撤回消息和事件均随私人会话注销清除。

新增 ChatInteractionTests 共 12 项，覆盖窗口、权限、重复操作、引用/搜索/摘要隐私、分页、通知抑制、个人清空、并发、事务失败回滚及注销隔离。与聊天和注销合并的 42 项定向测试通过。

本地联调脚本为 tools/smoke-chat-interaction-local.ps1，只创建 Java 合成账号，使用真实 2 分钟窗口，不改账号注销截止日期、不强制清理。
